# Code of Conduct

All project participants should communicate respectfully, focus on technical evidence and refrain from harassment, threats, discrimination, intentional disruption or publication of personal or credential data.

Constructive criticism of code, documentation, security design and architectural decisions is encouraged. Disagreements should address the technical substance rather than individuals.

Maintainers may edit or remove abusive comments, close disruptive discussions or restrict participation when necessary.

To report a conduct concern, contact the repository maintainer through a private GitHub channel if available. Do not include sensitive personal information in a public Issue.

This policy applies to Issues, Pull Requests, Discussions and other project-maintained collaboration spaces.
