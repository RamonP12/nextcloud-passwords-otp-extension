# Code of Conduct

Project participants should communicate respectfully, focus on technical evidence, and refrain from harassment, threats, discrimination, intentional disruption, doxxing or publication of personal or credential data.

Constructive criticism of code, documentation, security design and architectural decisions is encouraged. Disagreements should address technical substance rather than individuals.

Maintainers may moderate or remove abusive comments, close disruptive Issues or Pull Requests, and restrict participation when appropriate.

## Reporting a conduct concern

For **non-sensitive** moderation issues, open a [GitHub Issue](https://github.com/RamonP12/nextcloud-passwords-otp-extension/issues) without personal details, direct threats, identifying evidence or confidential material. The repository currently has **no Discussions forum**.

**A confidential conduct-reporting address has not yet been established.** GitHub Issues are public once the repository is published, GitHub has no direct-message feature, and Private Vulnerability Reporting is intended for **security vulnerabilities**, not general conduct complaints. Do not disclose sensitive evidence publicly. A future dedicated project mailbox can provide a confidential route only once its address and handling policy have actually been configured.

This policy applies to Issues, Pull Requests and other project-managed collaboration spaces.
